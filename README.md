# Githits-com Tap

## How do I install these formulae?

`brew install githits-com/tap/<formula>`

Or `brew tap githits-com/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "githits-com/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
